# StudentIQ Curated Demo Questions for Datathon Judges

These questions align directly with the official competition specifications:

| # | Question Prompt | Intent | Generated SQL Query | Recommended Chart | Business Insight |
|---|---|---|---|---|---|
| 1 | `Compare average test scores between schools with and without functional electricity.` | `ELECTRICITY_COMPARISON` | `SELECT CASE WHEN has_electricity THEN 'Functional Electricity' ELSE 'No Electricity' END as status, COUNT(*) as school_count, ROUND(AVG(avg_test_score), 1) as avg_test_score, ROUND(AVG(avg_student_attendance_pct), 1) as avg_attendance, ROUND(AVG(reported_dropout_rate_pct), 1) as avg_dropout_rate FROM schools GROUP BY has_electricity;` | Dual-Axis Bar Chart | Quantifies the academic performance premium in electrified institutions (+12 to 16 pts). |
| 2 | `Show the dropout rate by district.` | `DROPOUT_BY_DISTRICT` | `SELECT district, ROUND(AVG(reported_dropout_rate_pct), 1) as avg_dropout_rate, COUNT(*) as total_schools FROM schools GROUP BY district ORDER BY avg_dropout_rate DESC;` | Horizontal Bar Chart | Ranks districts by student attrition, identifying primary areas of vulnerability. |
| 3 | `Show attendance versus meal availability.` | `ATTENDANCE_VS_MEAL` | `SELECT CASE WHEN mdm_served_status THEN 'Mid-Day Meal Active' ELSE 'Mid-Day Meal Disrupted' END as meal_status, COUNT(*) as school_count, ROUND(AVG(avg_student_attendance_pct), 1) as avg_attendance, ROUND(AVG(reported_dropout_rate_pct), 1) as avg_dropout_rate FROM schools GROUP BY mdm_served_status;` | Bar Chart | Demonstrates attendance gains (+15-20%) associated with active Mid-Day Meals. |
| 4 | `Show the relationship between attendance and test scores.` | `ATTENDANCE_VS_TEST` | `SELECT school_id, school_name, district, avg_student_attendance_pct, avg_test_score, reported_dropout_rate_pct FROM schools ORDER BY avg_student_attendance_pct DESC LIMIT 100;` | Scatter Plot | Plots positive correlation between classroom attendance and exam marks. |
| 5 | `Which schools have the highest dropout risk?` | `HIGH_RISK_SCHOOLS` | `SELECT school_id, school_name, district, reported_dropout_rate_pct, avg_student_attendance_pct, infrastructure_score, retention_risk_level, priority_action FROM schools WHERE retention_risk_level IN ('CRITICAL', 'HIGH') ORDER BY reported_dropout_rate_pct DESC LIMIT 15;` | Horizontal Ranking Bar Chart | Dispatches field intervention taskforces to schools with compound welfare deficits. |
| 6 | `Show infrastructure gaps by district.` | `INFRASTRUCTURE_GAPS` | `SELECT district, COUNT(*) as total_schools, ROUND(SUM(CASE WHEN has_electricity THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 1) as electricity_pct, ROUND(SUM(CASE WHEN has_drinking_water THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 1) as water_pct, ROUND(SUM(CASE WHEN has_separate_girls_toilet THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 1) as girls_toilet_pct, ROUND(AVG(infrastructure_score), 1) as avg_infrastructure_score FROM schools GROUP BY district ORDER BY avg_infrastructure_score ASC;` | Grouped Bar Chart | Reveals district-level sanitation, water, and electrification gaps. |
